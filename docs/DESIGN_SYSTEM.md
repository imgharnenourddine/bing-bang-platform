# Design system

THE BIG BANG · Three worlds. One beginning. Mobile-first, strong typography, geometric accents, warm surfaces, accessible contrast and reduced motion. Respect supplied assets; do not invent official logos. Administration should remain simple and operational.

Display: Unbounded 800/900; body: Outfit 500/700. CSS declares fallback fonts when remote fonts cannot load. Tokens live in frontend/src/styles/index.css. Color combinations must be checked for contrast when building future UI; decorative accent colors are not automatically suitable as text.
