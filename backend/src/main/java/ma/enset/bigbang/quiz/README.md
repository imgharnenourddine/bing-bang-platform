# Quiz backend boundary

Owned by the Tech Lead; preserve existing contributions. This package is reserved for quiz lifecycle, questions and options, submissions, server-side answer validation and fixed-point scoring, synchronization, leaderboard and results. F06.1 implements the domain, repositories and V7 schema; services and controllers remain future work. Organize controllers, services, repositories, entities, DTOs, exceptions and events as needed. Reuse shared identities and `RealtimeEvents`; never put authentication, participant or WebSocket implementations here. See `docs/QUIZ_INTEGRATION.md`.
